# Training Projects Repository

A collection of frontend web development training projects, exercises, and interactive demos.

## 🚀 How to Run the Project

You can run this project in any of the following ways:

### Option 1: Open directly in Browser
Open [`index.html`](index.html) directly in any web browser.

### Option 2: Run via Node (Recommended)
```bash
npm start
```
This will launch a local web server displaying the projects hub.

### Option 3: Run via Python
```bash
npm run serve
# or directly:
python3 -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

## 📁 Available Projects & Modules

- **`STU_DBMS/`** - Student Information Database Management System
  - [`STU_DBMS/home.html`](STU_DBMS/home.html): Main dashboard, student list view, and popup modal for adding students.
  - [`STU_DBMS/Add.html`](STU_DBMS/Add.html): Dedicated student registration form.

- **`ALL3/`** - BMI Calculator
  - [`ALL3/index.html`](ALL3/index.html): Interactive Body Mass Index calculator.

  - [`AMG/AMG_HOME.html`](AMG/AMG_HOME.html): AMG Home interface.
  - [`AMG/index.html`](AMG/index.html): Registration & terms acceptance form.
  - [`AMG/amg_us_login.html`](AMG/amg_us_login.html): Among Us style login page.
- **`THREAD/`** - CSS Animation Showcase
  - [`THREAD/threadmill.html`](THREAD/threadmill.html): Threadmill continuous cards animation.
- **`MAP_OBJ/`** - Map / Object Data Demo
  - [`MAP_OBJ/login.html`](MAP_OBJ/login.html): Interactive map and object lookup demo.
